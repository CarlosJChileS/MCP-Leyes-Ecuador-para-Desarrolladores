# Contribuir

Instale con `npm ci` y ejecute `npm run check`. Antes de proponer una distribución, ejecute `npm run verify:package` y `npm run verify:scanners` (esta última necesita red).

Las contribuciones de código y documentación original se reciben bajo MIT. Los documentos oficiales enlazados y las dependencias conservan sus propios derechos y condiciones; no copie documentos de terceros al paquete sin comprobarlos.

Para modificar normativa, incluya el enlace oficial, artículo o sección, fecha y evidencia de publicación. Separe publicación, firma, accesibilidad, revisión documental y revisión jurídica. No cambie `pendiente_verificacion` a una vigencia afirmativa sin una revisión jurídica documentada. No registre a una persona como revisora si no realizó esa revisión.

Toda obligación debe incluir artículo, fuente, ámbito condicionado y evidencia sugerida en español e inglés. Una selección de artículos no es exhaustiva. Las referencias descubiertas automáticamente permanecen fuera del catálogo principal hasta su revisión.

Añada pruebas de regresión para defectos de contrato, seguridad y compatibilidad. No utilice secretos reales ni datos personales en fixtures. Los cambios incompatibles en nombres, parámetros o estructuras de respuesta requieren una versión mayor y guía de migración.
